## Running the collector

Use Python 3.10 or newer and install the dependencies with
`python3 -m pip install -r requirements.txt`. See the
[installation and configuration guide](docs/README.txt) for service setup.

Run the regression tests with `python3 -m unittest discover -s tests`.
